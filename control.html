Связь пульта с графикой

В облачном режиме пульт и графику можно открывать с GitHub Pages с любых компьютеров с интернетом. Пакет графики публикуется в комнату автоматически при выборе. Ключ комнаты — секрет: без него к титрам не подключиться.

Данные титров

Тексты, логотипы, цвета, таймеры и привязка полей текущего пакета.

Клавиши

Пробел — выбранный титр в эфир / из эфира (когда курсор не в поле) · Esc дважды — снять всё · ↑ ↓ — выбор титра

📡 Данные с табло

Приложение ScoreOCR на iPhone (и любая программа, которая умеет слать команды в vMix по HTTP API) обновляет поля титров: счёт, период, игровое время. Голы на табло сразу запускают анимацию «ГОЛ!».
