# GT Web CG — титры vMix GT и After Effects без vMix

Конвертер титров **vMix GT (.gtzip)** и **After Effects (Lottie .json из Bodymovin)** в веб-графику плюс пульт титрования в браузере. Архитектура та же, что у пакета «Гонки дронов 2026»: страница графики с прозрачным фоном идёт в vMix как Web Browser input, а пульт открывается отдельно, на любом компьютере.

| Страница | Что делает |
|---|---|
| `import.html` | Импорт: перетащить `.gtzip` (или `.zip` с папкой титров) и/или `.json` из After Effects → проверить анимацию → сохранить пакет в пульт или скачать `.json` |
| `control.html` | Пульт: список титров, каналы 1–4 (как оверлеи vMix), PREVIEW / PROGRAM, IN/OUT, редактирование полей, таймеры |
| `index.html` | Графика 1920×1080 с альфой для vMix → Add Input → Web Browser |

## Быстрый старт

**Облако (GitHub Pages):**
1. Откройте `https://<user>.github.io/gt-web-cg/import.html` и перетащите туда `.gtzip`. Нажмите «Сохранить в пульт».
2. В пульте откройте ⚙ Настройки, выберите режим «Облако: Firebase», скопируйте «Ссылку для vMix».
3. В vMix: Add Input → Web Browser → вставить ссылку, 1920×1080.

При выборе пакета пульт сам публикует его в комнату (`/cg/<комната>/pkg` в Firebase), и графика в vMix его подхватывает.

**Локальная сеть (без интернета):** запустите `node server.js` (или `start-server.command` на Mac, `start-server.bat` на Windows). Пульт: `http://IP:8787/control.html`, графика в vMix: `http://IP:8787/`. Порт 8787 выбран потому, что 8088 занят vMix.

## Что переносится из GT

- **Объекты:** Rectangle, Ellipse, TextBlock, Image, вложенные Layer.
- **Кисти:** сплошная заливка, линейный градиент (точки WPF пересчитываются точно), картинка.
- **Маски** (Mask Object): маска следует за анимацией своего объекта, поэтому текст «проявляется» вместе с плашкой.
- **Bounding:** плашка подстраивается под текст с Padding.
- **AutoSize** WidthAndHeight / Width / Height (точка Location не сдвигается) и **Shrink** (шрифт уменьшается, пока текст не влезет).
- TextEffect Uppercase, TextAlign, VerticalAlign, NoWrap.
- **Эффекты:** Shadow, FlipX/FlipY, Blur.
- **Storyboards:** TransitionIn, TransitionOut, DataChangeIn → DataChangeOut (с DataName), Continuous.
- **Анимации:** Fade, Reveal (Direction, CenterAxis), Expand, Fly, Zoom, Hidden; все Interpolation (Cubic/Quadratic/Sine/Back/Bounce/Elastic… In/Out/InOut); Delay, Duration, Reverse.
- **Поля данных** как в vMix Title Editor: текст `Имя.Text`, картинка `Имя.Source`, цвет фигуры (DataFlags=None) `Имя.Fill`, видимость (ShowVisible) `Имя.Visible`. Объекты с DataFlags=Hidden не редактируются.
- **Картинки** вшиваются в пакет. Одинаковые файлы хранятся один раз, а слишком большие уменьшаются до размера показа.
- **Шрифты:** GT их не вкладывает в архив. Montserrat встроен в репозиторий, остальные страница импорта скачивает с Google Fonts и вшивает в пакет; можно загрузить и свой `.ttf/.otf/.woff2`.

Чего страница импорта не переносит, она перечисляет в предупреждениях у каждого титра: Feather у Crop, Page-storyboards, неизвестные эффекты.

### Модель анимации (как её понимает конвертер)
- Анимация описывает **появление** объекта. В TransitionOut и DataChangeOut она проигрывается наоборот, как исчезновение.
- `Reverse="True"` зеркалит направление (Left↔Right, Top↔Bottom).
- `Hidden`: объект скрыт всё время storyboard и остаётся скрытым после него. Объект, которого в storyboard нет, виден.
- После storyboard сцена замирает в его конечном состоянии.
- Смена поля с DataChange-storyboard запускает DataChangeIn, затем DataChangeOut. Если поле поменяли во время появления, реакция сработает после In. На табло хоккея это даёт плашку «ГОЛ!»: она выезжает, держится ~4 с и уходит.

## Титры из After Effects (Lottie)

Анимации AE переносятся один в один: титр проигрывает экспорт Bodymovin через [lottie-web](https://github.com/airbnb/lottie-web) (MIT, `vendor/lottie.min.js`). В пульте такой титр работает как титр GT: каналы, правка полей, общие поля, таймеры, данные с табло.

**Подготовка в AE:**
1. Маркеры композиции: `in` — начало появления, `hold` — кадр, на котором титр стоит в эфире, `out` — начало ухода (уход играет до конца композиции). Без маркеров появление — вся композиция, уход — растворение 0,3 с.
2. Выражения (Animation Composer и т.п.) лучше «запечь» в ключи: в браузере они считаются иначе или не работают вовсе.
3. Режимы наложения «Preserve Transparency» (T) lottie не поддерживает. Замените их на Alpha Matte.
4. Bodymovin: Glyphs **выкл.**, Assets → Include in json **вкл.**, без сжатия.

**Импорт:** перетащите `.json` и файлы шрифтов (`.ttf/.otf`) на страницу импорта. Если один файл подходит ко всем начертаниям, есть кнопка «Файл шрифта для всех…». Импорт сам убирает пустые текстовые аниматоры Animation Composer, на которых lottie-web перестаёт рисовать слои, и предупреждает о невыпеченных выражениях, эффектах и 3D.

**Поля:** каждый текстовый слой → `<Имя слоя>.Text`; небольшие картинки (логотипы, эмблемы) → `<Имя слоя>.Source` и `.Visible`; значки-отметки вида `1-X`, `1-V` → только `.Visible` (по умолчанию выключены — например, попытки в серии буллитов). Фоны, узоры и линии (`BG`, `Pattern`, `Line`…) полями не становятся. Если текст слоя скопирован в маску (после подготовки T → Alpha Matte), копия меняется вместе с ним. Если слоям дать имена как в GT (`Счет 1`, `Счет 2`, `Период`, `Время`), данные ScoreOCR встанут на места автоматически. Время в формате `20.00` (с точкой) становится таймером мм.сс.

Текст в AE — точечный, поэтому длинное название не сжимается под рамку, а расширяется от точки выравнивания. Учитывайте это при вёрстке.

### Данные турнира с junior.fhr.ru

`tools/fhr-sync.js` собирает с сайта ФХР календарь всех групп (номер матча, дата, команды, города, логотипы, арена), турнирные таблицы, бомбардиров, составы команд (номер, амплуа) и тренеров, коды команд (ДИН, Л04…) → `data/fhr/<турнир>.json`, логотипы → `data/fhr/logos/`.
- **Облако:** GitHub Action `fhr-sync` запускает сбор каждые 15 минут (и вручную: Actions → fhr-sync → Run workflow) и коммитит изменения. Сайт не отдаёт данные в чужой браузер (нет CORS), поэтому пульт на GitHub Pages берёт их из репозитория.
- **Локально:** кнопка «⟳ Обновить с сайта» в окне «Матч» — server.js скачивает данные сразу.
- Другой турнир: `node tools/fhr-sync.js <часть-адреса-турнира>` или поле `tournament` при ручном запуске Action.

### Окна пульта для пакета ФХР
- **🏒 Матч** — выбор матча из календаря (поиск по №, командам, дате, группе). Кнопка «Заполнить титры» разносит по всем титрам названия, города, коды для табло (до 5 знаков), логотипы, турнир, арену, составы (вратари → защитники → нападающие, по номерам) и главных тренеров; таблицу группы матча и бомбардиров. «Коды команд…» — свои сокращения (можно вставить списком «Динамо Москва — ДИН»), хранятся в браузере и применяются ко всем матчам. Формат имён: ИМЯ ФАМИЛИЯ / ФАМИЛИЯ ИМЯ / И. ФАМИЛИЯ.
- **📈 Статистика** — броски, броски в створ, вбрасывания, штраф для обеих команд кнопками ± (сразу в титр и в эфир), выбор заголовка («после 1 периода»…), обнуление.
- **Удаления (доп. инфа 1/2)** — отдельные оверлеи на каналах 4 и 5 рядом с табло: состав («5 НА 4»…) и время удаления кнопками. При IN таймер стартует, идёт и стоит вместе с часами табло (вручную, клавишей или от ScoreOCR), на нуле титр уходит сам.
- **Выбор из состава** — в титрах игроков, тренеров, автора гола и ассистентов список игроков/тренеров команды заполняет номер, имя и амплуа.
- **Таблица / Бомбардиры** — над полями выбор группы (или весь турнир, места 1–5, 6–10…) и «Заполнить».
- **Горячие клавиши** (⚙ Настройки) — IN/OUT любого титра и выбранного, «Снять всё», часы старт/стоп, счёт ±1, статистика +1, окна «Матч» и «Статистика». Клавиши по физическому положению — работают в любой раскладке.
- **Скрыть титр** — ✕ у титра в списке (👁 в заголовке списка показывает скрытые).

### Пакет «ФХР · Кубок России»
`packages/fhr-kubok-rossii.json` — графический пакет ФХР из After Effects, 21 титр: заставка, шторка, табло (логотипы, коды команд), удаления хозяев/гостей, автор гола хозяев/гостей, счёт периода, буллиты, итоговый счёт, инфографика, составы хозяев/гостей, статистика, протокол, игроки и тренеры хозяев/гостей, турнирная таблица, бомбардиры. Каналы: крупные титры — 1, нижние — 2, табло и его варианты — 3, удаления — 4 и 5, шторка — 6.

Сборка из экспортов AE: `tools/fhr_package.py` (правки макетов: логотипы, дубли, таблицы — через `tools/lottie_kit.py`) → страница импорта → `tools/fhr_meta.py` (привязки полей к данным матча, разделы, выбор из состава, заготовки, таймеры удалений; одинаковые картинки — один раз в `pkg.assets`).

## Пульт

- **Каналы 1–4** работают как оверлеи vMix: титр в канале заменяет предыдущий, а разные каналы видны одновременно, например табло + нижний титр. Канал по умолчанию: полноэкранные титры → 1, титры в верху экрана → 3/4, остальные → 2. Поменять канал можно в списке.
- **🔗 Общие поля.** Поля с одинаковым именем и одинаковым значением в GT связаны: счёт, названия команд и логотипы меняются сразу во всех титрах. Связь можно снять кнопкой.
- **Правки:** по умолчанию идут в PREVIEW. В эфир их отправляет «⟳ Обновить в эфире», Enter в поле или галочка «правки сразу в эфир». Кнопки **±** у числовых полей и таймеры уходят в эфир сразу.
- **⏱ Таймер.** Любое текстовое поле можно превратить в таймер: старт/стоп, установка времени, прямой/обратный отсчёт, форматы мм:сс, м:сс, «м:сс → сс.д» (десятые на последней минуте), мм.сс и «м.сс → сс.д» (как на табло с точкой), чч:мм:сс. Время считает сама графика, поэтому таймер не зависит от задержек связи.
- **Логотипы:** выбор из картинок пакета или свой файл; он уменьшается под размер объекта.
- **Клавиши:** `Пробел` — IN/OUT выбранного титра, `↑ ↓` — выбор титра, `Esc Esc` — снять всё.

## Данные с табло (ScoreOCR)

Приложение ScoreOCR на iPhone распознаёт табло и обновляет поля титров: счёт, период, игровое время. Подойдёт и любая другая программа, которая умеет слать команды в vMix по HTTP API. Гол на табло сразу запускает анимацию «ГОЛ!».

- **Локально:** `server.js` понимает HTTP API vMix (`/api/?Function=SetText…`, `SuspendCountdown`, `StartCountdown`, `ChangeCountdown`, `PauseCountdown`, `StopCountdown`, `SetCountdown`, `AdjustCountdown`). В приложении укажи IP компьютера с server.js и порт 8787, больше ничего менять не нужно.
- **Облако:** в приложении выбери «Куда отправлять → GT Web CG (облако)», затем адрес базы и комнату из пульта (кнопка 📡 Табло). Команды идут в очередь `/cg/<комната>/ext/q`, пульт их забирает и удаляет.
- **Сопоставление полей** (📡 Табло): HomeScore → Счет1, AwayScore → Счет2, Clock → основной Таймер (20:00, а не штрафной 02:00), Period → Период. Работает автоматически по именам, любое поле можно переназначить. Числа дополняются нулями под формат титра («3» → «03»).
- Галочка «сразу в эфир» включена по умолчанию: данные с табло обновляют титры в эфире без нажатия кнопок. Пульт должен быть открыт, потому что он принимает данные и рассылает их в графику.

## Хранение пакетов

- Импорт сохраняет пакет в браузер (IndexedDB) на том же адресе, где открыт пульт.
- «Скачать .json» → положите файл в `packages/` и добавьте строку в `packages/index.json`: тогда пакет появится в пульте у всех в разделе «Из репозитория».
- Графику можно загрузить и напрямую из файла: `index.html?pkg=packages/hokkey-fhm.json` (плюс `&fb=…&room=…` для облака).

## Синхронизация

- **Облако:** Firebase Realtime Database через WebSocket (SDK в `vendor/`): одно соединение на страницу, поэтому браузер не упирается в лимит из шести HTTP-соединений на хост. Состояние лежит в `/cg/<комната>/state`, пакет в `/cg/<комната>/pkg`. Используется та же база, что у пакета дронов, правила открывают `/cg`. Ключи полей с точкой (`Счет1.Text`) кодируются, потому что Firebase запрещает точку в ключах. Таймеры считаются по серверному времени Firebase, так что пульт и графика на разных компьютерах идут секунда в секунду.
- **Локально:** `server.js` — `POST /api/state`, `GET /api/events` (SSE), `GET/PUT /api/pkg`. Последнее состояние и пакет сохраняются на диск.
- **Резерв:** BroadcastChannel + IndexedDB, если пульт и графика открыты в одном браузере.
