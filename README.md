# GT Web CG — титры vMix GT без vMix

Конвертер титров **vMix GT (.gtzip)** в веб-графику плюс пульт титрования в браузере. Архитектура та же, что у пакета «Гонки дронов 2026»: страница графики с прозрачным фоном идёт в vMix как Web Browser input, а пульт открывается отдельно, на любом компьютере.

| Страница | Что делает |
|---|---|
| `import.html` | Импорт: перетащить `.gtzip` (или `.zip` с папкой титров) → проверить анимацию → сохранить пакет в пульт или скачать `.json` |
| `control.html` | Пульт: список титров, каналы 1–4 (как оверлеи vMix), PREVIEW / PROGRAM, IN/OUT, редактирование полей, таймеры |
| `index.html` | Графика 1920×1080 с альфой для vMix → Add Input → Web Browser |

## Быстрый старт

**Облако (GitHub Pages):**
1. Откройте `https://<user>.github.io/gt-web-cg/import.html` и перетащите туда `.gtzip`. Нажмите «Сохранить в пульт».
2. В пульте откройте ⚙ Настройки, выберите режим «Облако: Firebase», скопируйте «Ссылку для vMix».
3. В vMix: Add Input → Web Browser → вставить ссылку, 1920×1080.

При выборе пакета пульт сам публикует его в комнату (`/cg/<комната>/pkg` в Firebase), и графика в vMix его подхватывает.

**Локальная сеть (без интернета):** запустите `node server.js` (или `start-server.command` на Mac, `start-server.bat` на Windows). Пульт: `http://IP:8787/control.html`, графика в vMix: `http://IP:8787/`. Порт 8787 выбран потому, что 8088 занят vMix.

## Что переносится из GT

- **Объекты:** Rectangle, Ellipse, TextBlock, Image, вложенные Layer.
- **Кисти:** сплошная заливка, линейный градиент (точки WPF пересчитываются точно), картинка.
- **Маски** (Mask Object): маска следует за анимацией своего объекта, поэтому текст «проявляется» вместе с плашкой.
- **Bounding:** плашка подстраивается под текст с Padding.
- **AutoSize** WidthAndHeight / Width / Height (точка Location не сдвигается) и **Shrink** (шрифт уменьшается, пока текст не влезет).
- TextEffect Uppercase, TextAlign, VerticalAlign, NoWrap.
- **Эффекты:** Shadow, FlipX/FlipY, Blur.
- **Storyboards:** TransitionIn, TransitionOut, DataChangeIn → DataChangeOut (с DataName), Continuous.
- **Анимации:** Fade, Reveal (Direction, CenterAxis), Expand, Fly, Zoom, Hidden; все Interpolation (Cubic/Quadratic/Sine/Back/Bounce/Elastic… In/Out/InOut); Delay, Duration, Reverse.
- **Поля данных** как в vMix Title Editor: текст `Имя.Text`, картинка `Имя.Source`, цвет фигуры (DataFlags=None) `Имя.Fill`, видимость (ShowVisible) `Имя.Visible`. Объекты с DataFlags=Hidden не редактируются.
- **Картинки** вшиваются в пакет. Одинаковые файлы хранятся один раз, а слишком большие уменьшаются до размера показа.
- **Шрифты:** GT их не вкладывает в архив. Montserrat встроен в репозиторий, остальные страница импорта скачивает с Google Fonts и вшивает в пакет; можно загрузить и свой `.ttf/.otf/.woff2`.

Чего страница импорта не переносит, она перечисляет в предупреждениях у каждого титра: Feather у Crop, Page-storyboards, неизвестные эффекты.

### Модель анимации (как её понимает конвертер)
- Анимация описывает **появление** объекта. В TransitionOut и DataChangeOut она проигрывается наоборот, как исчезновение.
- `Reverse="True"` зеркалит направление (Left↔Right, Top↔Bottom).
- `Hidden`: объект скрыт всё время storyboard и остаётся скрытым после него. Объект, которого в storyboard нет, виден.
- После storyboard сцена замирает в его конечном состоянии.
- Смена поля с DataChange-storyboard запускает DataChangeIn, затем DataChangeOut. Если поле поменяли во время появления, реакция сработает после In. На табло хоккея это даёт плашку «ГОЛ!»: она выезжает, держится ~4 с и уходит.

## Пульт

- **Каналы 1–4** работают как оверлеи vMix: титр в канале заменяет предыдущий, а разные каналы видны одновременно, например табло + нижний титр. Канал по умолчанию: полноэкранные титры → 1, титры в верху экрана → 3/4, остальные → 2. Поменять канал можно в списке.
- **🔗 Общие поля.** Поля с одинаковым именем и одинаковым значением в GT связаны: счёт, названия команд и логотипы меняются сразу во всех титрах. Связь можно снять кнопкой.
- **Правки:** по умолчанию идут в PREVIEW. В эфир их отправляет «⟳ Обновить в эфире», Enter в поле или галочка «правки сразу в эфир». Кнопки **±** у числовых полей и таймеры уходят в эфир сразу.
- **⏱ Таймер.** Любое текстовое поле можно превратить в таймер: старт/стоп, установка времени, прямой/обратный отсчёт, форматы мм:сс, м:сс, «м:сс → сс.д» (десятые на последней минуте), чч:мм:сс. Время считает сама графика, поэтому таймер не зависит от задержек связи.
- **Логотипы:** выбор из картинок пакета или свой файл; он уменьшается под размер объекта.
- **Клавиши:** `Пробел` — IN/OUT выбранного титра, `↑ ↓` — выбор титра, `Esc Esc` — снять всё.

## Хранение пакетов

- Импорт сохраняет пакет в браузер (IndexedDB) на том же адресе, где открыт пульт.
- «Скачать .json» → положите файл в `packages/` и добавьте строку в `packages/index.json`: тогда пакет появится в пульте у всех в разделе «Из репозитория».
- Графику можно загрузить и напрямую из файла: `index.html?pkg=packages/hokkey-fhm.json` (плюс `&fb=…&room=…` для облака).

## Синхронизация

- **Облако:** Firebase Realtime Database, REST + SSE. Состояние лежит в `/cg/<комната>/state`, пакет в `/cg/<комната>/pkg`. Используется та же база, что у пакета дронов, правила открывают `/cg`.
- **Локально:** `server.js` — `POST /api/state`, `GET /api/events` (SSE), `GET/PUT /api/pkg`. Последнее состояние и пакет сохраняются на диск.
- **Резерв:** BroadcastChannel + IndexedDB, если пульт и графика открыты в одном браузере.
